# Contributing

This project is a small research reference implementation. Contributions are most useful when they falsify or sharpen the core hypothesis rather than add framework surface area.

Good contributions include:

- counterexamples where execution-scoped allocations fail;
- clearer ownership/scope semantics;
- OpenTelemetry propagation experiments;
- A2A/MCP integration examples;
- exposure-log semantics;
- migration/conformance tests;
- examples of overlapping experiments in shared-agent graphs.

Please keep dependencies and abstractions minimal unless a concrete experiment requires them.
